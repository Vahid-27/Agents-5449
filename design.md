# Design System — Talsy Blog Writing Agent

## Brand
- Product: talsy.ai — AI recruitment/sourcing engine
- Voice: Professional, intelligent, clean

## Colors
- Primary Blue: #2563EB (blue-600)
- Light Blue: #EFF6FF (blue-50)
- Blue Accent: #1D4ED8 (blue-700)
- White: #FFFFFF
- Gray Text: #374151 (gray-700)
- Light Gray: #F9FAFB (gray-50)
- Border: #E5E7EB (gray-200)
- Success Green: #16A34A
- Warning Amber: #D97706
- Error Red: #DC2626

## Typography
- Display: "Plus Jakarta Sans" (headings, bold)
- Body: "Inter" (readable, clean)
- Mono: "JetBrains Mono" (code, HTML output)
- Scale: xs(12), sm(14), base(16), lg(18), xl(20), 2xl(24), 3xl(30)

## Layout
- Max width: 1280px centered
- Sidebar: 280px fixed left (agent pipeline nav)
- Main: flex-1 scrollable
- Padding: 24px standard, 16px mobile

## Components
- Cards: white bg, subtle border, 8px radius, light shadow
- Agent steps: numbered badges in blue, connected with vertical line
- Active agent: blue left border, blue bg tint
- Completed: green check badge
- Input fields: clean borders, blue focus ring
- Buttons: solid blue primary, ghost secondary
- Output sections: light gray bg, mono font for code

## Agent Pipeline Visual
- Left sidebar shows all 10 agents as steps
- Active step glows blue
- Completed steps show green
- Pending steps are gray
- Each agent has icon + name + status badge
- Main area shows active agent's UI

## Tone
- Clean, minimal, no clutter
- Plenty of whitespace
- Blue as the only accent color
- Professional SaaS feel
